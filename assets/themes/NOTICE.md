# Bundled VS Code themes

These color themes are compiled into the app unmodified so they're available without
VS Code installed. Only their workbench `colors` are used.

| Theme | Files | Source | License |
| --- | --- | --- | --- |
| Dark Modern, Light Modern (+ Dark+/Light+/Visual Studio bases they include) | `dark_*.json`, `light_*.json` | [microsoft/vscode `extensions/theme-defaults`](https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults) | MIT, [LICENSE-vscode.txt](LICENSE-vscode.txt) |
| Monokai | `monokai-color-theme.json` | [microsoft/vscode `extensions/theme-monokai`](https://github.com/microsoft/vscode/tree/main/extensions/theme-monokai) | MIT, [LICENSE-vscode.txt](LICENSE-vscode.txt) |
| Solarized Dark / Light | `solarized-*-color-theme.json` | [microsoft/vscode `extensions/theme-solarized-*`](https://github.com/microsoft/vscode/tree/main/extensions) | MIT, [LICENSE-vscode.txt](LICENSE-vscode.txt) |
| Night Owl | `night-owl-color-theme.json` | [sdras/night-owl-vscode-theme](https://github.com/sdras/night-owl-vscode-theme) | MIT, [LICENSE-night-owl.md](LICENSE-night-owl.md) |
